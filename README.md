# Getting started

## Repository layout

| Path | Role |
|---|---|
| [`data/`](data/) | Raw data exactly as downloaded from Web of Life (Gulf of Cadiz food web, `FW_005`). Never edited. |
| [`code/build_network.py`](code/build_network.py) | Cleans the raw matrix, builds the weighted directed network, derives trophic level and other node traits, and writes every file in `output/` and `figures/` |
| [`code/rq_feasibility.py`](code/rq_feasibility.py) | Rank-correlates trophic level with number of prey, number of predators, total degree, and diet diversity |
| [`output/`](output/) | Everything derived from the raw data: culled diet matrix, cleaning log, node traits (trophic level etc.), edge list, GraphML, one Excel workbook with all of it |
| [`output/cadiz_foodweb_data.xlsx`](output/cadiz_foodweb_data.xlsx) | The same tables as the CSVs, one sheet each, for opening in Excel |
| [`figures/`](figures/) | Figures generated by the code |
| [`manuscript/`](manuscript/) | Submitted drafts (proposal, introduction) as PDFs |
| [`PROJECT_STATUS.md`](PROJECT_STATUS.md) | Milestones, instructor feedback to address, open decisions |
| `requirements.txt` | Pinned Python packages |
| `CITATION.cff` | How to cite this repository |

## Installation

Python 3.13.

```bash
pip install -r requirements.txt
```

or, with conda:

```bash
conda create -n biol4559 python=3.13
conda activate biol4559
pip install -r requirements.txt
```

## Reproducing the results

From the repository root:

```bash
python code/build_network.py
python code/rq_feasibility.py
```

The first script takes about 5 seconds and rewrites everything in `output/` and `figures/` from `data/`. The second needs the first one's output.

## Data

Obtained from the Web of Life database, network `FW_005`. This work has used the Web of Life database (www.web-of-life.es). Details: [`data/README.md`](data/README.md).
