## Which file to use

Every figure is saved twice, from the same drawing:

| Format | Use it for |
|---|---|
| `.pdf` (vector) | **LaTeX / Overleaf.** Text stays sharp at any zoom. |
| `.png` (300 dpi) | Word, Google Docs, slides, GitHub |

## Size

Every figure is drawn at the size it prints, and no text in any figure is smaller than 6.5 pt at that size.

- **`01_web/`** figures are 7 in wide: the full text width of the two-column article template.
- **Every other figure** is 3.4 in wide: one column.

Insert them at that size. Shrinking a figure shrinks its text with it, which is what made Figure 1 of the proposal unreadable.

```latex
% one column (folders 02-06)
\begin{figure}
  \includegraphics[width=\columnwidth]{figures/05_node_removal/r50_summary.pdf}
  \caption{...}
  \label{fig:r50}
\end{figure}

% full width (01_web)
\begin{figure*}
  \includegraphics[width=\textwidth]{figures/01_web/cadiz_foodweb.pdf}
  \caption{...}
  \label{fig:foodweb}
\end{figure*}
```

In Word or Google Docs, insert the PNG at 3.4 in wide (or 6.5 in for `01_web/`).
