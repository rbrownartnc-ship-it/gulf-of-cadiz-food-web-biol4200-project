# Figures

This folder contains the figures in the manuscript. Both are drawn by [`code/build_network.py`](../code/build_network.py). To change a figure, edit the code and rerun it.

| File | What it shows | Used in |
|---|---|---|
| `cadiz_foodweb.png` | The food web drawn with height = trophic level. Node colour = broad category; node size = importance as prey (summed diet share); arrow width = diet share (prey → predator); ring = cannibalism. | Proposal, Figure 1 |
| `cadiz_diet_matrix.png` | The culled 43 × 43 diet matrix as a heatmap (log colour scale), with both axes ordered by trophic level. Category strips run along the axes, and cannibalism cells are outlined. | not yet |

Both are saved as 200-dpi PNGs.
