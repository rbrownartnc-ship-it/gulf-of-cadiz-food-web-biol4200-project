# Analysis notes

Each note is a written summary of one analysis: what was found, the values that support it, and the limitations. The notes are numbered to match the figure folders, so note 05 goes with `figures/05_node_removal/`. There is no note 07 or 09, since those two folders only hold the explainer figure and the connectivity panels. The full tables behind each note are in [`output/`](../output/README.md), and the methods, equations and references are in [`code/README.md`](../code/README.md).

| Note | Covers |
|---|---|
| [01 The web](01_web.md) | the data, cleaning steps, the cleaned network and trophic levels |
| [02 Distributions](02_distributions.md) | degree, link strength, trophic level, clustering and other distributions |
| [03 Structure](03_structure.md) | whole-web measures against random, degree-preserving and niche-model webs |
| [04 Centrality](04_centrality.md) | ten centralities and how they relate to trophic level |
| [05 Node removal](05_node_removal.md) | knockouts, guild removals, R50 by removal order and fragmentation |
| [06 Link removal](06_link_removal.md) | link knockouts, L50 by cutting order and fragmentation |
| [08 Comparison with other ecosystems](08_comparison.md) | the Gulf of Cadiz next to the Angolan shelf and the Mondego estuary, with the food webs, baseline statistics, the same measurements, and then intervals and tests |

The notes are written by hand, not generated by the code. If an analysis is rerun and a result changes, the tables in `output/` will be correct, but the note will need to be updated by hand.
