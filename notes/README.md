# Analysis notes

The key numbers from each analysis, one note per analysis. Each note has the number of its figure folder, so 07 (the explainer) and 09 (the connectivity panels) have no note of their own. The full tables are in [`output/`](../output/README.md), and the methods, equations and references are in [`code/README.md`](../code/README.md).

| Note | Covers |
|---|---|
| [01 The web](01_web.md) | data, cleaning steps, the cleaned network, trophic levels |
| [02 Distributions](02_distributions.md) | degree, link strength, trophic level, clustering and other distributions |
| [03 Structure](03_structure.md) | whole-web measures against random, degree-preserving and niche-model webs |
| [04 Centrality](04_centrality.md) | ten centralities and their relation to trophic level |
| [05 Node removal](05_node_removal.md) | knockouts, guild removals, R50 by removal order, fragmentation |
| [06 Link removal](06_link_removal.md) | link knockouts, L50 by cutting order, fragmentation |
| [08 Comparison with other ecosystems](08_comparison.md) | the Gulf of Cadiz beside the Angolan shelf and the Mondego estuary: food webs, baseline statistics, the same measurements, then intervals and tests |

These notes are not rewritten by the code. So, if a result changes, the tables in `output/` are the ones to trust until the note is updated.
